# IntegrationApp

Учебный проект для автоматического переноса данных XML из инженерного ПО Logikal в учетную систему 1С.

## О проекте

При проектировании оконных и дверных конструкций в Logikal формируется спецификация. Ручной перенос данных отнимает много времени.
Данное приложение автоматизирует этот процесс: считывает XML-файл, выгруженный из Logikal, преобразует в структуру и через COM-соединение формирует заказ на производство.

## Технологический стек

* **Язык и платформа:** C#, .NET 8.0
* **Работа с XML:** `System.Xml.Serialization`
* **Работа с конфигурацией:** `Microsoft.Extensions.Configuration` (JSON-провайдер)
* **Интеграция с 1С:** COM-соединение (`V85.COMConnector` через динамическую типизацию / Reflection)
* **Логирование:** Вывод результатов парсинга в консоль

## Как это работает

1. **Чтение конфигурации:** При запуске программа считывает настройки подключения к 1С, артикул продукции и путь к XML-файлу из `config.json`.
2. **Парсинг выгрузки LogiKal:** Данные о заказе и позициях изделий извлекаются из входного XML-файла в объектные модели (`LogikalData`).
3. **Создание заказа в 1С:** Приложение подключается к базе 1С через COM-объект, находит номенклатуру по артикулам и создает новый документ «Заказ на производство».

## Требования

* ОС Windows (необходима для работы технологии COM).
* Установленный [.NET SDK 8.0](https://microsoft.com) или выше.
* Установленная платформа **1С:Предприятие 8.5** с зарегистрированным COM-компонентом. *Важно: разрядность платформы (x86/x64) должна совпадать с разрядностью сборки C#-приложения для корректной работы COM-соединения.*
* Развернутая информационная база на базе конфигурации **1С:Управление нашей фирмой (УНФ)** (проект разрабатывался и тестировался на типовой демо-базе) с правами пользователя на создание заказов и подключение через внешнее соединение (COM).

### Инструкция

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/projectsavemail.git
   cd IntegrationApp
   ```

2. Создайте файл конфигурации `appsettings.json` на основе шаблона `appsettings.example.json` и укажите в нем путь к вашей базе 1С:УНФ, `ProgId` и путь к файлу из папки `samples/`. *Важно: тестовые артикулы из `appsettings.example.json` и `samples/` отсутствуют в типовой демо-базе по умолчанию — перед запуском создайте соответствующие позиции вручную в справочнике «Номенклатура» в 1С (или подставьте свои существующие).*

3. Запустите приложение:
   ```bash
   dotnet run --project IntegrationApp/IntegrationApp.csproj
   ```

Так как проект создан в учебных целях, в текущей версии есть ряд упрощений:
* Парсер адаптирован под упрощенную структуру XML-файла (пример находится в папке `samples/`).
* Используется единый базовый артикул из `appsettings.json` для заполнения номенклатуры в заказе.
* Основная логика парсинга и взаимодействия с 1С сосредоточена в `Program.cs`.
* Отсутствует валидация входных данных и обработка исключений (программа рассчитана на корректный входной файл).
